Keyboard shortcuts

WinBliss can be driven entirely from the keyboard.

Canvas (editing)

←→↑↓move selected elements
Shift+arrows / dragfine grid (1 unit)
Rrotate (cycles the four orientations)
Dduplicate
Deletedelete selected
⌘/Ctrl+Zundo
⌘/Ctrl+Aselect all elements
⌘/Ctrl+clickadd/remove from selection
double-click text elementedit its text

Shape palette

Tab → family, Enteropen family; focus jumps to its first shape
←→browse shapes
Enter/Spaceadd the focused shape to the canvas

Symbol lists

clickopen the symbol in the editor
⌘/Ctrl+click, Shift+clickmulti-select, range select
F2edit gloss & synonyms (Enter saves, Esc cancels)
drag a rowreorder in place · drag to the other list copies (Shift moves) · drop on the canvas to merge

Everywhere

?this help
Escclose any dialog
$ then C/S/O/H copy · save · open · start page — pressed one at a time, nothing held down; the same keys in every WinBliss part ($? lists them)
